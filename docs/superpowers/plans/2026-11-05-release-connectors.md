# 正式交付连接器续建计划

在已经验证的工程基础上继续推进 P3。沿用已批准的需求、独立质量和正式发布门禁，不把接口测试当成商店或设备验收。

- [x] 持久渠道查询：发布节点按需查询，审核等待释放资源；失败保留上一次已知状态，不重新提交发布；查询结果不能替代独立验收。
- [x] 内置可信 publisher：批准制品的摘要校验、项目与渠道固定映射、持久操作日志、未知结果禁止盲重试。
- [x] Google Play AAB 提交与渠道查询：服务账户、edit/upload/track/commit，按官方 API 能力如实记录审核边界。
- [x] Web / 桌面分发：不可变制品、Web 原子切换、签名更新索引、桌面系统签名校验、公开下载与版本追溯。
- [x] 工作台查询入口、部署样例、恢复手册与验收记录；运行对应后端、浏览器和实际本地分发检查。

本批不声称完成尚无条件验证的原生签名、真机、真实商店上架与两个正式应用。App Store 及国内商店完整连接器、私钥服务、全栈运行监测与企业规模化能力继续保留为产品缺口。
