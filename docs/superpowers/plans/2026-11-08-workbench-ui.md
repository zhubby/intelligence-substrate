# Dual-theme Agent delivery workbench

## Approved boundaries

Rebuild the login, application shell, six existing navigation entries and nested
business surfaces with Mantine, Ant Design X, read-only React Flow and selected
Tremor Raw components. Keep API commands, permissions, approval gates, accessible
labels, native selection and existing recovery behavior unchanged. Default to a
new dark theme and persist an explicitly selected light theme. Do not deploy,
commit, overwrite untracked work, use paid models or change existing services.

## Execution checklist

- [x] Add failing theme and presentation regressions against the existing UI.
- [x] Install compatible dependencies without bypassing peer validation.
- [x] Implement shared semantic tokens, CSP-safe theme bootstrap and providers.
- [x] Migrate public UI adapters, login, shell, forms, dialogs and notifications.
- [x] Migrate all six entries and nested governance/recovery surfaces.
- [x] Add version-bound read-only task graphs and evidence-backed charts.
- [x] Remove obsolete Looseleaf implementation and overrides.
- [x] Extend isolated browser runner with dark/light and tablet coverage.
- [x] Run type/build, complete business matrix and visual/accessibility checks.
- [x] Record evidence and provide an isolated local preview without deployment.

## Visual direction

Graphite backgrounds, layered panels, cyan actions and explicit semantic states
in dark mode; cool grey backgrounds, white surfaces and high-contrast text in
light mode. Share a 14px typography scale, local CJK coverage, restrained shadows
and 120–180ms transitions. Keep status text, respect reduced motion and never
invent activity, trends, costs or missing measurements.

## Validation

Use the existing Go-backed isolated Playwright harness and deterministic local
model fixtures. Cover both themes, desktop/mobile business suites, 390/768/1440px
screenshots, 200% zoom, CSP, keyboard/focus behavior and empty/unknown data. New
builds, synthetic state, reports and preview assets belong to a unique work/
directory. Existing screenshots are historical references, not a fresh baseline.

Completed on 2026-11-09: 144 desktop/mobile and dark/light suite groups, 328
passing tests (312 browser cases plus 16 presentation-adapter cases), no skipped,
unexpected or flaky tests. Six 390/768/1440px theme combinations produce 90
screenshots; four additional actual 200% browser-zoom combinations produce 60
viewport screenshots. Final type checking, isolated production build, formatting,
reduced-motion computed styles and preview health checks pass. Evidence and the
remaining low-severity dependency advisory are recorded in `docs/workbench-ui.md`.
