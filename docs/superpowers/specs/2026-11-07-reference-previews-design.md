# 首批 Flutter/Go 蓝图的完整开发预览

本设计落实已批准产品规划中的「可运行开发预览」，继续沿用主线程执行、主线程评审；不提交 Git、不变更现有 18080 服务，不使用真实发布账户或付费模型。

## 已确认的问题

两个准确来源的既有 Flutter Web 包均含 `.last_build_id`，被静态预览归档安全规则拒绝。私有、一次性变换包的 Chrome 156 实测表明：去掉构建元数据后 Flutter/CanvasKit 已能在原有不透明 origin 沙箱运行；根 base 被 CSP 拒绝，而编译固定 API 被 connect-src 正确阻止。该探针不作为实际构建或业务验收证据。

仅调整静态构建可提供页面展示，但不能完成反馈与预约；允许访问任意后端 URL 会引入生产数据和网络访问边界。因此本增量采用预览专用包、独立执行节点与受控业务 API，不放开外网、Web Worker 或同源权限。

## 交付范围

1. `web-preview` 构建配置在真实 Worker 中编译 Flutter 与 Linux Go 后端；常规 `web` 发布包保持原有语义。专用包去掉 Flutter 构建元数据和根 base，客户端从当前文件路径解析预览 API。
2. 根部静态文件及 `substrate-preview/manifest.json`、`substrate-preview/backend` 在同一不可变 tar.gz 中。清单 schemaVersion=1、profile=flutter-go-v1，声明 mode、Linux 架构、后端大小/SHA256。保留原有 64 MiB、32 MiB/文件、10,000 项限制；保留目录不对浏览器提供文件。
3. 配置了独立预览节点后才能创建带后端的预览。原有人工权限、短期访问凭据、需求/仓库/提交/制品绑定逐请求生效。预览不生成独立质量或正式发布证据。
4. 网关只新增首批蓝图的精确 JSON 路由：健康、反馈列表/创建、预约时段、预约/取消。请求不接受查询、升级、Cookie、Authorization、自定义转发头；单请求至多 16 KiB，响应至多 512 KiB。不自动重试业务写入；结果不明明确提示刷新核对。

## 执行与隔离

控制面仅持有预览节点 Unix socket；`cmd/preview-node` 独立持有 Docker 权限、私有状态目录和管理员构建的可信 relay。socket 位于节点的 0700 目录，权限 0600，不提供 TCP 入口；同一 OS 用户属于可信服务管理边界。节点不接受任意 URL、宿主机路径、命令或环境变量。

每个 previewId 与不可变 binding 对应一个 scratch 容器。节点将准确后端与可信 relay 导入仅含这两个普通可执行文件的独有镜像。容器 network=none，无宿主机端口/目录/设备/socket；只读 rootfs、非 root、cap-drop ALL、no-new-privileges、PID/内存/CPU 限制，`/data`、`/tmp` 为有限 tmpfs。RPC 通过 `docker exec` 运行可信 relay，relay 仅请求容器自身 127.0.0.1:8081。不存在通往任意宿主机或生产后端的代理。

业务数据为单预览临时数据，容器重建/停止后丢失。不同预览不共享数据。控制面每 15 秒核对节点实例与当前权威预览，正常情况下停止/基线失效在下一次维护时回收。节点维护执行租约，控制面连续 60 秒无法续租后停止实例；节点故障时可信容器监督进程在预览绝对期限结束后退出，最迟 240 分钟。资源边界与 Docker 引擎隔离不等于独立内核，敌对多租户仍需企业专用节点或更强执行后端。

节点在执行前持久化 intent，成功后持久化 receipt。启动或回收结果不明进入 uncertain，重复 ensure 不重放启动；已有 stopped 实例不自行复活，需要创建新预览。节点重启读取 journal，准确绑定与仍有效租约继续使用原实例。回收只操作拥有节点 owner、previewId、binding 标签的容器/镜像，冲突资源保持原样；不创建共享网络/卷。

## 验收

- 单元/集成测试覆盖保留文件、摘要/架构、禁用节点、请求方法/路径/体积、凭据剥离、CORS、不重试、绑定冲突、资源上限、租约/终态、持久化和结果不明。
- 两个当前源码应用经准确 Git 提交、真实 Worker 编译后进入实际网关/节点/Docker/Chrome，在 1440/390px 完成反馈提交及预约、冲突、取消；验证两个预览互不共享数据。
- 核对实际 Docker inspect 的隔离参数，节点/控制面恢复、停止后拒绝、容器/镜像回收，以及现有静态预览与 HTTPS 入口回归。
- 原始凭据、短期 URL、日志、二进制与诊断留在 work；输出脱敏源码包、报告、运行说明、证据和截图，独立回读。

## 总体边界

本增量推进研发预览，不关闭 Apple 许可/原生构建、Windows 真实运行、移动真机、企业签名和资质、商店上架、生产交付及两个应用全端正式发布的缺口。
