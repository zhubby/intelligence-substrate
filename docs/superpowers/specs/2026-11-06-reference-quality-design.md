# 同制品参考应用自动质量与报告

本增量落实已批准的质量验证中心、证据可追溯和两种业务参考验收。上一轮首次调度机制已完成，接下来让真实参考应用通过同一平台构建制品完成实际业务验证，并持久保存报告。

## 受保护的报告

pipeline增加可选reportPath，只能由现有人类quality/owner创建，限定工作区内普通相对路径，不接受绝对路径、父级跳转或保留控制器文件。该字段属于pipeline快照，自动策略沿用内容摘要校验。普通外部plan不能通过任务字段覆盖策略报告路径。

可信Worker在测试命令结束后读取该文件，通过原租约上传type=report，准确绑定原run/仓库/提交/交付目标。成功但缺报告进入blocked，不创建通过证据；失败且已产生报告也保存其字节，原失败与缺陷处理不改写为通过。没有配置reportPath的既有策略保留日志行为。

控制面结果完成事务验证reportArtifactId确属本run、当前质量身份、项目/目标/版本/源码与实际package，校验真实字节。成功配置报告时必须有报告；失败给出报告ID也必须验证。passed evidence保存proofArtifactId及报告摘要，发布门槛重新检查报告完整性和绑定。报告内容是实际测试输出，平台不把JSON文字声明当作独立事实。

## 单应用真实浏览器策略

新脚本对一个明确application根目录、当前IS_ARTIFACT_PATH与受保护参数中的loopback API地址工作；不依赖另一份外部构建manifest。安全校验压缩包条目、数量、总大小、路径、重复项与普通文件类型后才展开，拒绝链接/特殊文件/越界和歧义资源路径；静态服务限制根目录。

从Worker检出的准确源码构建真实Go后端，使用随机隔离状态与固定诊断API端口，已有监听则拒绝，不接管服务。后端与站点仅loopback，浏览器只允许声明的本地origin，实际检查输入校验、重复提交、普通文本/脚本、预约冲突与取消权限、不透明凭据、后端重启持久性、离线恢复和390px布局。生成结构化报告和截图归档，记录制品SHA256、源码摘要、实际检查及清理结果；退出码决定Worker结果。

该脚本是参考蓝图的已知业务验收，不能验证任意生成业务。手机宽度是Chrome布局，不是移动真机。开发/质量/发布负责人测试身份明确为验收样本。

## 实际平台验收

在隔离控制面从当前蓝图新建feedback/booking应用，各自导入平台Git、批准需求和构建方案，绑定browser/automated策略，实际Worker构建带明确本地API的Web包。质量Worker轮询触发自动调度，实际脚本测试同一下载包、上传报告，控制面生成准确证据并允许待批准候选。无人工pipelines.run、无借用旧包与证据，不执行真实发布。

如果成功，证明平台同制品的Web研发到独立质量/候选流程；完整P3依然要求原生iOS/Android/Windows/macOS、真机、真实签名/渠道及两个应用全部必选端正式交付。本轮不以缺少账号或Apple许可为理由缩小原产品目标。
