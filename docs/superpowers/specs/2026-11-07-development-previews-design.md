# 发布前 Web 开发预览

本增量落实已批准产品规划中的可运行开发预览。沿用代码仓库、Worker 构建与不可变制品；不修改正式发布和独立质量门禁。按当前会话授权顺序实现，不使用子 Agent、不提交 Git。

## 产品范围

开发人员或项目内开发 Agent 从当前已批准需求版本的 Web package 制品创建预览。预览固定仓库、完整提交、制品 SHA256/size 和需求版本，可设置 5–240 分钟有效期，默认 60 分钟；每项目最多 10 个未到期的活动预览。创建、停止均要求稳定请求 key 和原因，停止绑定准确预览 revision。旧请求重放返回当前状态，不能重新启用过期、停止或失效预览。

工作台代码页显示当前仓库、目标的可用构建包和预览，支持创建、打开、停止。查看者可打开；只有开发权限可创建、停止。明确展示来源、有效期与失效状态。需求变更立即使旧预览失效。预览不产生测试证据、不通过验收、不创建发布或部署记录。

本期支持 tar/tar.gz 的多文件静态 Web 包及普通脚本、ES modules、CSS、图片、字体和本地数据请求。包入口为根 index.html，资源使用相对路径。后端服务、任意开发命令、热更新、Service Worker、Web Worker、外网请求、凭据 API、WebSocket 与完整 IDE 不在本增量范围；界面如实说明支持范围。

## 隔离入口

控制面可选配置 IS_PREVIEW_LISTEN、IS_PREVIEW_URL；生产 URL 必须 HTTPS 且与控制面不同 hostname，开发 HTTP 只允许 loopback。预览 listener 仅提供自己的固定路径，没有控制面 API、Git、生产分发或代理功能。未配置时 UI 展示明确原因。入口必须保持独立 hostname、host-only Cookie，代理日志不得记录预览 URL。

已登录人工会话通过受 CSRF 保护的 POST 请求领取最多 10 分钟的随机访问链接；期限同时受预览与原会话期限限制。凭据只保留摘要，使用 credentials 的独立 preview 类型，不能用于平台 Bearer/Basic/会话鉴权，备份恢复不包含它。链接属于敏感短期凭据，不能写入资源、审计、日志、知识或持久前端状态。每个会话持有人最多保留 20 个未到期链接。

每次 wrapper、状态和文件请求都在同一事务检查访问摘要、原人工会话、账户启用状态、当前项目权限、准确预览、需求版本和绑定制品。退出登录、成员/团队权限变化、停用账户、停止和到期后，旧链接拒绝后续请求；权限恢复不复活已撤销链接。已传输到浏览器的内容不能召回。

可信 wrapper 使用 iframe sandbox=allow-scripts，父 CSP 仅允许该链接的 files 路径，阻止应用导航到外部和控制面。子文档保持 opaque origin，以 CSP 限制网络到自身文件路径；只为静态资源提供无凭据 CORS。禁用表单、弹窗、顶层导航、嵌套 frame、worker、Service Worker。wrapper 定时检查状态，失效后移除 iframe。文件 URL 单独打开也受 sandbox CSP；HTML 仅作为 iframe 加载，避免脱离父导航边界运行。

## 包完整性与资源约束

一次读取最多 64 MiB 已登记归档，核对 size/SHA256 后解析；展开总量不超过 64 MiB，单文件最多 32 MiB，最多 10,000 条目。只允许普通文件和目录，拒绝重复、符号/硬链接、设备、路径逃逸、隐藏路径、异常 gzip、缺失入口和尾随非零 tar 数据。内存包没有文件系统解压或网络行为。网关仅缓存最近一个经过摘要验证的不可变包；缓存命中仍检查当前业务权限，缓存内容是首次验证过的原始字节。损坏原文件不会修改已验证缓存，重启/换包后重新核对源归档。

## 验证

先编写有意义的失败测试：完整多文件预览、非法归档、准确绑定、幂等状态、过期、停止/需求变化、跨项目与身份边界、CSRF、链接不能充当平台 token、登录退出/成员与团队撤权、审计故障回滚、真实 PostgreSQL 并发与备份恢复。浏览器验证 1440/390px 的创建/体验/停止、模块与本地数据、网络与导航隔离、加载/错误、Escape/焦点和无横向溢出。另用实际平台/Worker 进程从 Git 源码构建包并在 Chrome 体验。保留原预览、261 索引条目、587 源文件中无关内容、275 份既有输出及原 Docker/AVD 状态。
