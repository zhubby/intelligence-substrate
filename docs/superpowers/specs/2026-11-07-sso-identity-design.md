# 企业 SSO 稳定身份边界

继续已批准产品规划中的企业身份与权限。一个平台实例内，同一 OIDC issuer/subject 只能绑定一个已开通的人类身份；停用账户保留绑定，不允许借邮箱变化重新绑定到另一账户。已有冲突数据拒绝登录，不能自动选取或合并账户。未开通身份、空主体、无效登录状态、重复回调均不得创建会话。

首次绑定仍要求提供方签名、issuer/audience、有效期、PKCE、nonce、已验证邮箱和预先开通的企业账户。邮箱仍用于查找待绑定身份；绑定后不得静默迁移身份。主体保持原始大小写和字节。当前账户、唯一绑定和成功审计在现有串行 SQL 事务核对；会话签发继续重新检查当前账户状态。

临时登录状态必须具有可解析且尚未到期的时间、非空 nonce/PKCE，并只能消费一次；不以 RFC3339 字符串字典序判断时间。SQL 读取/消费使用请求上下文和现有事务，不把 state/code/token 写入审计。

验证使用真实 SQL、HTTPS、本地签名 OIDC 提供方和实际浏览器/平台进程。提供方是隔离验收夹具，不代表真实企业 IdP、MFA、账号生命周期或生产验收。原预览、暂存、367 份旧输出、Docker、AVD 和 keychain 保持原状；不调用付费模型、真实商店/生产或代为接受 Apple 协议。完整多端正式交付目标保持开放。
