# 同源多端本地模型试验与接续

2026-11-07，本轮 054 试验**未能实现反馈优先级功能**。真实模型调用、失败与平台阻塞已经独立读回；没有成功的模型业务提交、对应多端构建或通过的优先级质量证据。完整 P2/P3 继续开放。

## 样本与固定输入

同一个 Flutter/Go 反馈应用声明 Web、Android、iOS、Windows、macOS 五端必选。固定蓝图提交为 `9612c66d00caceab7ea52bcb4c608287586cf845`，共 143 份文件。原生项目 scaffold、任务配方和本地负责人批准均由操作者提供；它们不证明模型能自主理解、分解或批准企业需求。

业务目标是在 JSON API 和 Flutter UI 增加 `priority`，取值为 `normal` 或 `urgent`。仅省略字段默认 normal；显式空串、未知字符串、大小写错误或前后空格均须 422 且不写入。UI 提供“优先级”的“普通”与“紧急”，失败提交保留输入和选择，成功后重置普通，POST/GET 与后端重启保留准确值。原有反馈、预约、持久化与离线逻辑受保护。

独立本地 Ollama 服务使用 `qwen2.5-coder:7b`，7.6B、Q4_K_M、context 32768，禁用 cloud。模型权重 4,683,074,048 字节，原始 manifest 摘要为 `dae161e27b0e90dd1856c8bb3209201fd6736d8eb66298e75ed87571486f4364`。六个 blob、原始 manifest、Ollama 追加 manifest 层与 Apache 2.0 许可证已逐字节核验。默认模型服务保持原样。

累计 60 次真实模型请求：3 次规划、24 次原开发、9 次越界开发、24 次聚焦后端。提供方报告的 59 次用量合计 prompt 927,436、completion 24,635、total 952,071 token；另一次超时的用量未知，**这些数字不是完整 token 总量**。报告协议完成的 58 次响应不代表任务成功，另有一次截断和一次传输错误；模型没有发出 finish。

模型价格配置为输入/输出 0 USD/M，仅表示此配置下的推理金额估价为零。超时费用由本地合成负责人依据私有 loopback、禁用 cloud 与零单价核对为 0，原 transport_error、未知用量、已消耗调用次数与活动时间保留。它不表示机器、电力或人工成本为零。

同一个后端任务三次领取时已用调用为 0、2、4，实际分别新增 2、2、20 次。重试继承原累计时间和额度。旧 24 次任务没有靠普通重试扩额，改变任务配方均经过新的本地合成批准。

## 企业接续方式

1. 以[产品验收](product-acceptance.md)保留完整五端及渠道门槛。此次试验归为失败，不能推进完整 P2/P3 状态。
2. 接入企业授权且已做小规模代码编辑验证的模型，预先声明访问策略、预算、时限和模型参数。先验证单文件读取、短编辑、真实编译/业务测试及停止行为，再逐步扩大任务。
3. 新执行保留准确需求、计划与基线提交。当前失败任务配额已用尽，继续需要新批准方案；检查已放弃候选的状态，不重置或删除原分支。
4. 操作者版本化知识、重规划、调整模型等待/采样或提示时，记录前后配置、原因与影响。当前样本存在多次此类介入，不能计为自主规划成功。
5. 在可信原生节点前核对实际源码、允许改动的文件和提交父链；开发自报完成不足以触发构建或发布。平台目前仍需继续完善通用的代码变更范围约束；本次额外范围检查是私有验收程序，不宣称已有产品化强制路径策略。
6. 只有实际候选构建成功后，运行当前版本全部受保护质量场景。通过证据绑定新源码、准确制品与独立身份，旧 red、模拟器和合成批准不能替代真机/正式发布证据。
7. 用户处理 Apple 许可后按[Apple 构建接续](apple-reference-builds.md)核对 SDK 与实际编译；Windows、企业签名、真机、主体/账户及生产环境继续分别取得证据。

公开应用源码包是上述 **143 文件固定基线**，未包含可采用的模型实现。坏候选、原始模型会话、数据库、权重、密钥、原始设备/质量归档均保留在私有工作目录，不放入交付包。
