# 参考应用 A：客户反馈

## 业务基线

外部用户提交标题/说明并查看最新反馈列表。首个参考版本不含账号、工单处理、附件、付费或通知。新增这些业务须修订基线和计划。参考源码允许公开展示反馈，企业必须先确认隐私范围，不将敏感反馈作为公开样本。

## 验收

| ID | 行为 | 最低验证 |
|---|---|---|
| F1 | 合法反馈提交成功，在列表显示相同内容 | API 自动化 + 各必选端业务流程 |
| F2 | 缺标题/超长输入被拒绝，列表不出现半写入数据 | API 自动化 + 界面错误交互 |
| F3 | 服务重启后记录保留 | 持久化重启测试 |
| F4 | 网络不可达时显示错误，可再次刷新；加载时防止重复提交 | 真实浏览器/目标系统/移动真机 |
| F5 | 内容按普通文本展示，不执行用户脚本 | 真实交互安全测试 |
| F6 | 安装/公开访问的版本与已批准制品一致 | 各渠道发布后独立核对 |

2026-11-06 已通过实际生成项目的后端 race 测试、Flutter analyze、9 项 widget 测试与 Web release 构建。Chrome 对包内真实站点和实际 Go API 验证了 F1–F5 的浏览器部分：空标题拦截、重复点击只写一次、内容按普通文本显示、离线刷新恢复及后端进程重启保留数据。中文和拉丁字体随包分发，浏览器另检查未声明外部请求。1440×1000 与 390×844 截图及制品摘要见 [验证记录](../validation.md)。F2 的 UTF-8 长度边界另由 widget/API 测试覆盖；浏览器检查不能代替各必选端和真机验收。

## 交付声明

后续同制品验收已把新应用的实际Flutter构建、自动质量调度、真实Chrome业务检查、归档报告和待审批候选串在平台内，见[质量报告](../reference-quality.md)。证据绑定该次准确package、提交和质量run；没有借用早期外部包的浏览器结果。仍未公开发布。

Android arm64 调试包另通过专用模拟器的空标题、真实提交、客户端/服务端重启和网络恢复检查；恢复场景要求刷新后读到新服务端记录。该轮输入为 ASCII 测试数据；UTF-8 边界另由 widget/API 检查。具体 APK 摘要、签名与设备指纹见验证记录，没有借用 Web 结果声称真机通过。

完整参考交付需显式选择 web、ios-appstore、android-google-play、android-huawei、android-xiaomi、android-oppo、android-vivo、windows、macos。企业提供应用标识、隐私页面、账号、证书、可达 API 和设备。Web 记录部署/冒烟，移动端记录签名包/提审/审核/上架/真机，桌面记录签名安装包/公开分发/更新。现有本地构建及交互证据不满足 F6 或完整交付。
