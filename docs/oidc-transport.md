# 企业 SSO 传输与证书边界

生产单点登录要求 issuer、发现文档中的授权端点、令牌端点和 JWKS 地址均为完整 HTTPS URL，包含有效主机且不含用户信息或片段。缺失、HTTP、相对地址和不安全 URL 使配置失败，平台不启动该登录配置。端点允许使用不同的 HTTPS origin，也允许端点自带合法查询参数。

## 配置与证书

管理员配置 `IS_PUBLIC_URL`、`IS_OIDC_ISSUER`、`IS_OIDC_CLIENT_ID`、`IS_OIDC_CLIENT_SECRET_FILE`，在提供方登记准确回调，并先开通企业邮箱身份。凭据文件由运行平台的账户读取，不写入请求业务对象。身份与恢复规则见[SSO 稳定身份](sso-identity.md)。

默认客户端沿用系统证书信任与代理设置，不自动忽略证书错误。私有 CA 应按企业部署方式安装到受控运行环境，或在启动平台进程前通过 Go 支持的 `SSL_CERT_FILE` / `SSL_CERT_DIR` 指定。此类环境变量不是平台的证书校验关闭开关；必须验证预期 CA、实际主机和证书有效期。不要仅因浏览器能打开 IdP 就认定控制面也信任该证书。

嵌入调用方通过配置上下文提供的 HTTP 客户端，其受信任 transport、代理、cookie jar、重定向策略和更短超时会保留。平台复制客户端配置，避免修改共享客户端；普通入站请求不能用自己的上下文客户端替换配置时已捕获的 OIDC 客户端。

## 发现、交换与取钥

平台的发现请求、令牌交换和 JWKS 请求在实际交给底层 transport 前检查 URL，包括 HTTP 客户端跟随的每一跳重定向。HTTPS 到 HTTP、用户信息或片段目标会在网络前拒绝。合法 HTTPS 重定向继续工作，原自定义拒绝重定向策略不会被放宽。

发现配置有15秒上下文时限，客户端每次请求最长15秒；调用方配置的更短超时继续生效。令牌交换与令牌验证共用15秒总时限，避免 OAuth 库切换客户端认证方式时重新获得完整等待时间。令牌交换保留调用方取消语义。库共享的 JWKS 后台取钥可能在调用方取消后继续，仍受独立的客户端请求时限约束；本轮不声明后台取钥立即取消。

发现或元数据不安全时启动失败。运行中的令牌/JWKS 降级或证书失败会拒绝登录，不发放会话、不绑定身份、不记录成功 SSO 审计。有效 state 已在网络操作前一次性消费；失败后重新点击登录，旧回调不能重新交换。禁止把授权码、state、Cookie、nonce、PKCE verifier 或客户端密钥写入代理/APM/访问日志。

## 授权导航与网络策略

平台校验交给浏览器的初始授权端点。浏览器离开平台后，IdP 页面及其后续浏览器重定向由提供方和企业策略控制；服务端 HTTP 客户端的检查无法拦截这些导航。企业需独立验证完整登录页面、MFA 和回调流程。

HTTPS 限制不等于主机白名单、出网隔离、可信 IdP 审核或内容安全判断。提供方配置与发现文档属于管理员信任范围，企业仍应限制出网目的地和代理权限。本轮保留开发模式 HTTP 兼容，不应在生产启用开发模式。

## 验证

```sh
rtk proxy go test -race ./internal/httpapi -run 'TestOIDC' -count=1 -timeout=3m
```

测试使用实际 TLS/HTTP 接收端、签名 ID token、真实 SQL、nonce 和 S256 PKCE。明文接收端仅记录计数与是否出现测试凭据，不记录值。覆盖不安全元数据、发现/交换/取钥降级、无会话或绑定、副作用与重放、合法 HTTPS 跳转、跨 HTTPS origin、查询参数、私有 CA 信任延续、取消、更短超时和停滞请求。

独立真实进程演练包括四种启动拒绝、两种运行回调拒绝，以及允许 HTTPS 跳转后的浏览器登录、项目操作和强制重启恢复。私有 CA 不进入宿主 keychain；浏览器证书放行仅在隔离上下文中使用。结果见[验收记录](validation.md)。这些本机证据不证明真实企业 IdP、MFA、SCIM、离职联动、企业容量或正式多端交付已通过。原生端、真机、企业签名、商店和生产仍需实际验收，完整 P3 尚未完成。
